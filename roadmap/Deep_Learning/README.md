# AEGIS — Deep Learning Engineering Roadmap

This directory is dedicated to Deep Learning architectures, PyTorch implementations, Neural Network optimization, Computer Vision, and Sequence Modeling.

---

## Roadmap Scope

- **Neural Foundations**: Perceptrons, MLP, Backpropagation from scratch, Custom Loss Functions.
- **Optimization & Dynamics**: Adam, AdamW, Learning Rate Schedulers (Cosine Annealing, OneCycleLR), Weight Decay, Batch Normalization, Layer Normalization, Dropout.
- **Computer Vision**: Convolutional Neural Networks (CNNs), ResNets, Data Augmentation, Transfer Learning.
- **Sequence & Language Modeling**: RNNs, LSTMs, Attention Mechanisms, Transformer Architectures.
